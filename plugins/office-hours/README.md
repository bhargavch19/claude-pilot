# office-hours

Product interrogation before any code is written: is the problem real, who
has it, and is this idea worth building? Use for brainstorming, evaluating a
new product idea, or thinking through a design direction.

Vendored from garrytan/gstack (MIT).

## Install

```
/plugin marketplace add bhargavch19/claude-pilot
/plugin install office-hours@pilot
```

Wires no hooks and no MCP servers — adds one skill. Works standalone;
[pilot](../../README.md) offers it as a fallback in phase 1 (Frame) when the
question is product viability rather than design.
