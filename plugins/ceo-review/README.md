# ceo-review

Adversarial review of a drafted plan: challenge the proposal, poke holes in
the approach, think bigger about scope, and decide whether to expand, reduce,
or kill it. Use before committing to a multi-day build.

Vendored from garrytan/gstack (MIT).

## Install

```
/plugin marketplace add bhargavch19/claude-pilot
/plugin install ceo-review@pilot
```

Wires no hooks and no MCP servers — adds one skill. Works standalone;
[pilot](../../README.md) offers it as a fallback in phase 2 (Plan) for
strategic challenge of a drafted plan.
